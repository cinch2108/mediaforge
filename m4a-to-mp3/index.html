      About the m4a to mp3

      iPhone Voice Memos, GarageBand exports and iTunes purchases use M4A, an AAC audio file in an MP4 container. Most devices play it, but some car stereos, older Android apps, transcription services and podcast tools still want MP3. This page converts M4A to MP3 locally. That matters for voice memos, which are often personal or confidential, such as interviews, meetings and lectures, and should not be uploaded to unknown servers.

      How to use it

      1. AirDrop or copy your voice memos to your computer, then drop the .m4a files here.
      2. MP3 is preselected. Choose a bitrate (128 kbps suits voice).
      3. Process.
      4. Download the MP3s.

      Tips for the best results

      • Voice memos are mono speech, so 64–96 kbps MP3 is plenty and keeps files tiny.
      • Use Normalize Audio afterwards if the recording is quiet.
      • DRM-protected M4P files from old iTunes purchases cannot be converted.

      Settings explained

      How the settings work: MP4, MOV and MKV use H.264 video with AAC audio, WebM uses VP8 with Opus, and the audio formats use LAME MP3, AAC, Vorbis, FLAC or 16-bit PCM WAV. The quality setting maps to the encoder's constant rate factor, so the encoder spends bits where the picture needs them instead of using a fixed bitrate. Fast remux copies streams with no re-encoding when the target container supports them, and quietly falls back to a normal conversion when it does not.

      Why use Mediaforge for this: other m4a to mp3 sites upload your file to their servers, make you wait in a queue, and often add a watermark or cap the file size unless you pay. Here the work is done by FFmpeg compiled to WebAssembly, running in a background Web Worker in this tab. Your file is read straight from your disk, processed in memory and handed back as a download, so the counter above always reads 0 bytes uploaded.

      Frequently asked questions

      Can I convert iPhone voice memos?

      Yes. They are standard M4A files.

      Does it work with M4B audiobooks?

      Yes, though very long audiobooks need plenty of device memory.

      Is quality lost?

      Slightly, because both formats are lossy. At 128 kbps or more it is not noticeable for speech.

      Is it private?

      Yes. Files never leave your device.
