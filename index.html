Questions

Is it really free with no watermark?

Yes. There is no server doing the work, so there is nothing to meter. Output files are exactly what FFmpeg produces.

How fast is it compared to desktop software?

WebAssembly FFmpeg is slower than native FFmpeg, roughly 3–10× for heavy video encodes. You skip the upload and download entirely, though, so for most clips it finishes sooner than upload-based sites. Audio jobs, GIFs, muting and fast trims are near-instant.

Which formats are supported?

Input: almost anything FFmpeg reads, including MP4, MOV, MKV, WebM, AVI, FLV, 3GP, MP3, WAV, M4A, AAC, OGG, Opus and FLAC. Output: MP4 (H.264), WebM (VP8/Opus), MOV, MKV, GIF, MP3, WAV, M4A (AAC), OGG (Vorbis) and FLAC.

Does it work on my phone?

Yes, on modern mobile browsers, though phones have less memory, so keep files smaller there. Screen recording needs a desktop browser.
