      About the rotate & flip video

      Phones occasionally save video sideways, and front-camera footage is often mirrored. This tool rotates video by 90° clockwise, 180° or 90° counter-clockwise, and can flip it horizontally (mirror) or vertically. It actually re-encodes the frames rather than just setting a rotation flag, so the result looks right in every player and editor, including those that ignore rotation metadata.

      How to use it

      1. Drop your sideways or upside-down videos.
      2. Choose a rotation (90°, 180° or 270°) and optionally flip.
      3. Process.
      4. Download the corrected MP4s.

      Tips for the best results

      • Use horizontal flip to un-mirror front-camera selfie videos and make on-screen text readable.
      • Rotating 90° swaps width and height, so landscape becomes portrait.
      • Batch rotate a whole folder of clips from the same shoot.

      Settings explained

      How the settings work: rotation uses FFmpeg's transpose filter for 90° and 270° turns and a combined flip for 180°, and the mirror options use hflip and vflip. The frames are actually re-encoded rather than flagged with rotation metadata, so the result displays correctly in every player.

      Why use Mediaforge for this: other rotate & flip video sites upload your file to their servers, make you wait in a queue, and often add a watermark or cap the file size unless you pay. Here the work is done by FFmpeg compiled to WebAssembly, running in a background Web Worker in this tab. Your file is read straight from your disk, processed in memory and handed back as a download, so the counter above always reads 0 bytes uploaded.

      Frequently asked questions

      Will rotating reduce quality?

      The video is re-encoded at high quality, so the difference is very small.

      Why does my video look rotated in one app but not another?

      Some apps ignore rotation metadata. This tool rotates the actual pixels, so it looks right everywhere.

      Can I rotate by 45°?

      Only 90° steps are supported.

      Is it free?

      Yes. It is unlimited, with no watermark.
