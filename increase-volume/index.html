      About the increase volume

      Quiet phone recordings, soft-spoken interviews and videos recorded from across a room can be hard to hear. This tool applies a precise gain in decibels, from −20 dB to +20 dB, to audio files or to the soundtrack of a video. For video, the picture is copied untouched, so only the audio is re-encoded. You can also add a fade-in and fade-out. If you want a consistent, broadcast-style loudness instead of a fixed boost, use the Normalize option.

      How to use it

      1. Drop your audio or video files.
      2. Set the gain. +6 dB is roughly "twice as loud" to the ear.
      3. Optionally add a fade-in or fade-out in seconds.
      4. Process and download.

      Tips for the best results

      • Large boosts on noisy recordings make the noise louder too.
      • If the result distorts, lower the gain or use Normalize, which limits peaks.
      • Video quality is unaffected, because only the audio is processed.

      Settings explained

      How the settings work: Gain applies a fixed change in decibels (+6 dB is roughly twice as loud to the ear). Normalize uses the EBU R128 loudnorm filter to target −16 LUFS integrated loudness with a −1.5 dBTP true-peak ceiling. Fades are applied after the level change. For video files, the picture stream is copied untouched.

      Why use Mediaforge for this: other increase volume sites upload your file to their servers, make you wait in a queue, and often add a watermark or cap the file size unless you pay. Here the work is done by FFmpeg compiled to WebAssembly, running in a background Web Worker in this tab. Your file is read straight from your disk, processed in memory and handed back as a download, so the counter above always reads 0 bytes uploaded.

      Frequently asked questions

      How much louder can I make it?

      Up to +20 dB, which is about four times as loud to the ear.

      Will it distort?

      It can if the audio is already near maximum. Normalize avoids this.

      Does it work on video?

      Yes. Video is copied untouched and only the audio is changed.

      Is there a limit?

      No artificial limits.
